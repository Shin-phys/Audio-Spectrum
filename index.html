状態：停止中 / Pause中はスペクトルをスナップショット固定（クリックしても変化しません）。
注意：このアプリは HTTPS または localhost 上でのみマイクが使えます。マイク許可を拒否した場合は取得できません。
操作メモ： Startでマイク開始 / Pauseで表示停止（データ保持）/ Resetで完全初期化。 Pause中はドラッグでズーム、Zで2点選択へ切替。Escでカーソル情報とA/B解除。 CSVはPause中のみ（V）。
音の大きさ（dB）：マイクに入る最大の大きさの正弦波を 0 dB とした値（dBFS）です。騒音計の dB とは基準が違うので、 「基準にする」で 0 dB を決め、そこからの差（例：腹は節より 15 dB 大きい）で比べてください。値は端末やマイクの感度で変わります。
班ごとに周波数をずらす実験：「周波数を絞る」をオンにし、データ数 N を 32768、幅を ±3 Hz 程度にすると、 10 Hz ほどずれた隣の班の音をほぼ除いて、自分の班の周波数の音の大きさだけを測れます。 N が小さいと周波数の区別が粗くなるので、ずらす量の目安は上の表示を見てください。
